📘 React Day 5 — useEffect + API
1. useEffect na enna?
useEffect is a React Hook used to perform side effects in a component.

Examples:
API call
Timer
Event listener
Document title update

Import:
import { useEffect } from "react";

Basic syntax:
useEffect(() => {
  console.log("Effect running");
}, []);

2. Dependency Array
Dependency array illa
useEffect(() => {
  console.log("Runs");
});

➡️ Every render-ku apram run aagum.
Empty []
useEffect(() => {
  console.log("Runs once");
}, []);

➡️ Component initial render-ku apram run aagum.
[count]
useEffect(() => {
  console.log("Count changed");
}, [count]);

➡️ count change aagumbodhu effect run aagum.
⭐ Remember
No []   → Every render
[]      → Initial render
[count] → count change

3. useEffect + State
const [count, setCount] = useState(0);

useEffect(() => {
  console.log("Count changed");
}, [count]);

Flow:
setCount()
   ↓
count changes
   ↓
Component re-render
   ↓
useEffect runs

4. Cleanup Function
Effect create panna timer/event listener madhiri resources-ai clean panna cleanup function use pannuvom.
useEffect(() => {
  const timer = setInterval(() => {
    console.log("Running...");
  }, 1000);

  return () => {
    clearInterval(timer);
  };
}, []);

return () => {} → cleanup function.

Remember:
setInterval    → clearInterval
setTimeout     → clearTimeout
addEventListener → removeEventListener

12. Error Handling — try/catch
API fail aagalaam.
try {
  // API code
} catch (error) {
  console.log(error);
}

React state:
const [error, setError] = useState("");

Example:
try {
  const response = await fetch(url);

  const data = await response.json();

  setUsers(data);
} catch (error) {
  setError("API failed");
}

13. finally
Success/error edhu nadandhaalum finally run aagum.
finally {
  setLoading(false);
}

So:
try     → API attempt
catch   → Error handle
finally → Loading stop

⭐ Complete API Pattern
import { useEffect, useState } from "react";

function Users() {
  const [users, setUsers] = useState([]);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState("");

  useEffect(() => {
    async function getUsers() {
      try {
        const response = await fetch(
          "https://jsonplaceholder.typicode.com/users"
        );

        if (!response.ok) {
          throw new Error("Request failed");
        }

        const data = await response.json();

        setUsers(data);
      } catch (error) {
        setError("API failed");
      } finally {
        setLoading(false);
      }
    }

    getUsers();
  }, []);

  if (loading) {
    return <h1>Loading...</h1>;
  }

  if (error) {
    return <h1>{error}</h1>;
  }

  return (
    <>
      {users.map(user => (
        <div key={user.id}>
          <h2>{user.name}</h2>
          <p>{user.email}</p>
        </div>
      ))}
    </>
  );
}

Small important point ⭐
fetch() 404/500 response vandhaalum automatically catch pogadhu. Adhanala:
if (!response.ok) {
  throw new Error("Request failed");
}

use pannradhu better.
