⭐ Complete Validation Pattern
function handleSubmit(e) {
  e.preventDefault();

  setSuccess("");

  const newErrors = {
    name: "",
    email: "",
    password: ""
  };

  if (formData.name.trim() === "") {
    newErrors.name = "Name is required";
  }

  if (formData.email.trim() === "") {
    newErrors.email = "Email is required";
  } else if (!formData.email.includes("@")) {
    newErrors.email = "Enter a valid email";
  }

  if (formData.password.trim() === "") {
    newErrors.password = "Password is required";
  } else if (formData.password.length < 6) {
    newErrors.password =
      "Password must be at least 6 characters";
  }

  setErrors(newErrors);

  if (
    newErrors.name ||
    newErrors.email ||
    newErrors.password
  ) {
    return;
  }

  setSuccess("Registration successful");

  setFormData({
    name: "",
    email: "",
    password: ""
  });
}

🎤 Day 4 Interview Questions & Answers
1. What is a controlled input in React?
A controlled input is an input whose value is controlled by React state.

2. How do you manage multiple form inputs using one state?
We can store all input values in an object state.
const [formData, setFormData] = useState({
  name: "",
  email: ""
});

3. Why do we use name in an input?
It helps identify which input field is being changed.

4. What is e.target.name?
It gives the name of the input that triggered the event.

5. What is e.target.value?
It gives the current value of that input.

6. Why use [e.target.name]?
It dynamically updates the property matching the input's name.
[e.target.name]: e.target.value

7. What does preventDefault() do?
It prevents the browser's default form submission behavior.

8. Why use trim() in validation?
It removes surrounding whitespace and helps reject whitespace-only values.

9. How do you display separate errors for each field?
Store the errors in an object state.
const [errors, setErrors] = useState({
  name: "",
  email: ""
});

10. How do you reset a controlled form?
Set its state values back to their initial values.
setFormData({
  name: "",
  email: "",
  password: ""
});
