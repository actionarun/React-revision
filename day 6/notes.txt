📘 React Day 6 — React Router
1. React Router na enna?
React SPA-la different URL-ku different component display panna React Router use pannuvom.

Example:
/          → Home
/about    → About
/products → Products

Page full reload aagama component change aagum.
2. Install React Router
npm install react-router-dom

3. BrowserRouter
Routing work aaguradhukku application-ai BrowserRouter-kulla wrap pannuvom.

Usually main.jsx:
import { BrowserRouter } from "react-router-dom";

createRoot(document.getElementById("root")).render(
  <BrowserRouter>
    <App />
  </BrowserRouter>
);

Simple meaning:
BrowserRouter
     ↓
Routing enable
     ↓
<App />

4. Routes & Route
App.jsx:
import { Routes, Route } from "react-router-dom";

function App() {
  return (
    <Routes>
      <Route path="/" element={<Home />} />

      <Route
        path="/about"
        element={<About />}
      />

      <Route
        path="/products"
        element={<Products />}
      />
    </Routes>
  );
}

Meaning:
Routes → Route collection

Route → URL + Component

path    → URL
element → Display panna component

5. Link
Page navigate panna:
import { Link } from "react-router-dom";

<Link to="/">Home</Link>

<Link to="/about">About</Link>

Link yen?
Normal:
<a href="/about">About</a>

browser navigation/page reload cause pannalaam.

React Router:
<Link to="/about">About</Link>

client-side routing use panni SPA navigation pannum.

Remember:
Route → entha URL-ku enna component?

Link → antha URL-ku navigate panna

6. NavLink
Link madhiri dhaan. Aana active link identify panna useful.
import { NavLink } from "react-router-dom";

<NavLink to="/about">
  About
</NavLink>

Navbar active page styling-ku useful.
Link    → Navigation
NavLink → Navigation + Active state

7. useNavigate
JavaScript/function moolama navigate panna useNavigate.
import { useNavigate } from "react-router-dom";

function Login() {
  const navigate = useNavigate();

  function handleLogin() {
    navigate("/dashboard");
  }

  return (
    <button onClick={handleLogin}>
      Login
    </button>
  );
}

Example flow:
Login successful
      ↓
navigate("/dashboard")
      ↓
Dashboard page

Useful situations:
Login success
Registration success
Form submit success
Logout

8. Dynamic Routes
Suppose products:
Product 1
Product 2
Product 3

Separate details URLs:
/products/1
/products/2
/products/3

Route:
<Route
  path="/products/:id"
  element={<ProductDetails />}
/>

:id → dynamic URL parameter.
9. useParams
Dynamic URL value get panna useParams.
import { useParams } from "react-router-dom";

function ProductDetails() {
  const { id } = useParams();

  return <h1>Product ID: {id}</h1>;
}

URL:
/products/10

Then:
id → "10"

Important: URL params usually strings.
10. Dynamic Link
Product list:
{products.map(product => (
  <div key={product.id}>

    <h2>{product.name}</h2>

    <Link to={`/products/${product.id}`}>
      View Details
    </Link>

  </div>
))}

If:
product.id = 5

URL becomes:
/products/5

11. useParams + API
Real project-la romba useful.

URL:
/users/5

Get ID:
const { id } = useParams();

API:
useEffect(() => {
  async function getUser() {
    const response = await fetch(
      `https://example.com/users/${id}`
    );

    const data = await response.json();

    setUser(data);
  }

  getUser();
}, [id]);

Flow:
/users/5
   ↓
useParams()
   ↓
id = "5"
   ↓
API /users/5
   ↓
User details

12. 404 / Not Found Route
Wrong URL enter panna:
<Route
  path="*"
  element={<NotFound />}
/>

* → other unmatched routes.

Example:
/hello123
     ↓
No matching route
     ↓
NotFound

⭐ Basic Router Structure
function App() {
  return (
    <>
      <Navbar />

      <Routes>
        <Route path="/" element={<Home />} />

        <Route
          path="/about"
          element={<About />}
        />

        <Route
          path="/products"
          element={<Products />}
        />

        <Route
          path="/products/:id"
          element={<ProductDetails />}
        />

        <Route
          path="*"
          element={<NotFound />}
        />
      </Routes>
    </>
  );
}

Navbar:
function Navbar() {
  return (
    <nav>
      <Link to="/">Home</Link>

      <Link to="/about">
        About
      </Link>

      <Link to="/products">
        Products
      </Link>
    </nav>
  );
}

🎤 Day 6 Interview Questions & Answers
1. What is React Router?

React Router is a library used for client-side routing in React applications.
2. What is BrowserRouter?

BrowserRouter provides routing functionality to the React application using the browser's History API.
3. What is Routes?

Routes contains and matches route definitions.
4. What is Route?

Route maps a URL path to a React element/component.
<Route path="/about" element={<About />} />

5. What is Link?

Link is used to navigate between routes without doing a normal full-page navigation.
6. Difference between Link and NavLink?
Link
→ Basic navigation

NavLink
→ Navigation + active state

7. What is useNavigate?

useNavigate is a hook used for programmatic navigation.
navigate("/dashboard");

8. What is a dynamic route?

A dynamic route contains a variable URL segment.
<Route
  path="/products/:id"
  element={<ProductDetails />}
/>

9. What is useParams?

useParams is a hook used to access dynamic URL parameters.
const { id } = useParams();

10. Difference between Route and Link?
Route
→ URL-ku entha component render aaganum
  nu define pannum.

Link
→ Andha URL-ku navigate panna use pannuvom.

Idhu nee munnadi doubt ketta important question da ⭐
